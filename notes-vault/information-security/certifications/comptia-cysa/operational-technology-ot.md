### Operational Technology (OT)
The hardware and software that monitors and controls physical devices, processes, and events in the real world.  
IT systems process data, OT systems control things.  
e.g.) Valves, Pumps, Turbines, Conveyor Belts, Circuit Beakers.  

OT systems **do not have to support** manufacturing or an **industrial process**.  
Building automation, fire-control systems, and physical access-control systems are also examples of OT.

**IT**: CIA Triad. Confidentiality has highest priority.   
**OT**: AIC Triad. Availability comes first as downtime can has physical consequences.  

OT Frameworks: NIST SP 800-82, IEC 62443

#### Sensors
Measure real-world conditions like temperature, pressure, flow rate, voltage.  

#### Actuators
On the output side that receive commands and physically do something like open a valve, start a motor, activate a relay.  

#### Programmable Logic Controllers (PLCs)  
Specialized industrial computers built to be rugged, reliable, and to respond to inputs and outputs in real time.  
PLCs takes a sensors reading, runs its logic and sends a command to an actuator.  
They have extremely limited logging capabilities compared to standard IT systems.  

#### Human Machine Interface (HMI)
The screens ad control panels that operators use to monitor and interact with the OT environment.  
e.g.) Touchscreen panel, Software running on workstation in control room.  
HMIs on Windows workstations are normally IT systems tightly couped with OT processes and are often running on older, unpatched versions.  

#### Control Servers
Coordinate the overall operation of the OT environment, managing the flow of commands and data between the high-level business network and the OT network.  

#### Data Historian
A specialized database that stores all the historical operational data generated by the control loop.  
Records pressure readings, temperature logs, production rates, and every output  from every sensor.  
Reviewing Data Historian data is the OT equivalent of reviewing SIEM logs.  

### OT Security

#### Industrial DMZ/ IDMZ  
Sites between the corporate IT network and the OT control network where all communication between IT and OT passes through it.  

#### Data Diode  
A hardware device that allows data to flow in only one direction.  
e.g.) Data can flow from OT to IT for reporting and BI but commands cannot flow from IT back to OT.  

#### Patching  
Some OT system are EOL and have no new patches.  
Some OT processes can’t be stopped for maintenance windows.  

Compensating Controls like application whitelisting used to reduce risk.  
Network Segmentation reduces exposure to untrusted networks.  
Host-based firewalls can also be used to restrict network connections.  

#### Remote Access  
Should go through a dedicated jump server or bastion host in the IDMZ.  
MFA should be mandatory.  
All remote sessions should be logged and recorded for audit purposes.  
Vendor remote access should be time-limited, role-specific and removed after maintenance (JIT).  

#### Safety Instrumented Systems (SIS)  
Designed to take over and safely shut down a process if it does outside safe operating parameters.
