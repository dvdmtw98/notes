### Industrial Control Systems (ICS)
System of hardware and software components that controls and automates industrial processes.  
Used in power plants, water treatment facilities, oil refineries, manufacturing lines.  

Security Tools: Claroty, Dragos, Nozomi Networks  
In OT environment, active scanning is often prohibited.  

DCS and SCADA are both commonly used ICS architectures.

#### Programmable Logic Controller (PLC)
Runs the control logic for individual processes: reading sensor inputs, executing programmed instructions, and sending commands to actuators.  
PLCs are all connected together in a control loop (sense-compare-act).  

#### Control Server
Manages process states, coordinates between PLCs, and gives operators visibility into what the entire system is doing.  
Ties all the PLCs together into a coherent process.  

#### Human-Machine Interface (HMI)
The interface operators use to monitor the system, set operating parameters, and intervene when something goes wrong.  

#### Data Historian
A specialized time-series database that stores all operational data generated by the ICS.  

### ICS Communication Protocols
Specialized industrial protocols designed for reliability and deterministic timing **not security**.  

#### Modbus
Oldest and most widely used ICS protocols.  
It has no authentication or encryption.  

#### DNP3
Used heavily in utilities, especially for power distribution and water systems.  
Has some security but it was not the primary focus.  

#### EtherNet/IP and PROFINET
Offers somewhat better integration with IT networks but still carries legacy security assumptions.
