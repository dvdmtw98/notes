Custom fields need to be created before they are used in an incident.

![[xsoar-custom-fields.png|500]]

It is **recommended** to stick with **default field types** when possible.  
Fields are associated with **all incident types** by default.  
It is possible to configure **scripts** that execute when the **value in a field changes**.

[Working with Incident Fields \| Cortex XSOAR](https://xsoar.pan.dev/docs/incidents/incident-fields)
